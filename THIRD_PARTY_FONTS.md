# Bundled fonts

Roloam bundles two open-source typeface families for its optional destination lettering.
The full SIL Open Font License 1.1 notices are included in
`app/src/main/assets/font_licenses/` and are distributed with the APK.

## Doto

- Author: The Doto Project Authors / Óliver Lalan
- Source: https://github.com/oliverlalan/Doto
- Font: `app/src/main/res/font/doto_black.ttf`
- License: SIL Open Font License 1.1 (`app/src/main/assets/font_licenses/doto_ofl.txt`)

## Geist Mono

- Author: The Geist Project Authors / Vercel
- Source: https://github.com/vercel/geist-font
- Fonts: `app/src/main/res/font/geist_mono_regular.ttf`, `app/src/main/res/font/geist_mono_bold.ttf`
- License: SIL Open Font License 1.1 (`app/src/main/assets/font_licenses/geist_ofl.txt`)

Both families are bundled locally, so font selection never requires network access.
